## 5. 남은 한계

- 앱은 블로그 통계·제휴사 실적·유입 검색어를 직접 가져오지 않아 — 붙여넣기·입력·파일만.
- 개선안은 자동 작가(하루 세 번)가 쓰고, 블로그 글은 사용자가 직접 고쳐야 해.
- 추천 규칙의 숫자(조회 100 이상·클릭 30 이상·검색어 3회 이상 등)는 앱이 정한 기준이야.
