## 3. 내가 정한 것 (사용자가 따로 정하지 않은 부분)
- **다른 사람 사진·블로그 글은 가져오지 않음**: 허락된 사진 사이트·공공누리·앱이 그린 카드·직접 찍은 사진만. 잘 나가는 글은 구조만 숫자로 남기고 문장은 저장하지 않음.
- **AI 말투 점수는 참고용**: 경고·참고로만 보이고 발행을 막지 않음. 다듬기도 사람이 눌러야 요청되고, 다듬은 원고는 다시 '검수 필요'.
- **투자 글 기본 = 투자 블로그 채널**: 주제를 섞으면 블로그 주제 집중도가 흐려진다는 이유로 기본값을 분리로 둠. 두 번째 블로그가 아직 없으면 설정에서 '같은 블로그에 올림'으로 바꾸면 돼 (원고에 붙는 채널 이름만 달라지고 글은 그대로).
- **한국은행 대조는 누를 때만**: 자동으로 숫자를 가져와 글에 넣지 않음 (원고 숫자는 자동 작가가 출처에서 확인, 사람이 대조).
- **미국 지수 자동 대조는 안 넣음**: 무료로 쓸 수 있다고 확인한 공식 API를 못 찾았고, FRED 의 S&P 지수 자료는 저작권 표시가 있어서 뺐어. 기업 공시(DART)도 이번엔 안 넣음.
- **Unsplash 는 검색만**: Unsplash API 가이드라인이 "어디에 쓰든 API가 준 주소로 보여줘야 한다"고 해서, 앱이 사진을 복사해 두지 않고 사용자가 Unsplash에서 받아 올리게 함.

## 8. 고침 (2026-11-03 밤) — 글 목록·홈판에 대표 사진이 안 뜨던 것
- **무슨 일이었나**: 사용자가 원고 미리보기를 사진째 긁어서 네이버 편집기에 붙임 → 사진이 네이버에 올라간 게 아니라 앱의 **1시간짜리 서명 주소로 연결만** 됨 → 글 안에는 보이지만 네이버가 대표 사진으로 못 잡아서 글 목록에는 글자 카드만 나옴 (사용자 화면 2026-11-03 21:50·21:58 — "[종목 한 장 정리] 삼성전자 3분기…" 글은 안에 썸네일이 보이는데 목록엔 글자만. 같은 목록의 "K-세일페스타 온누리상품권…" 글도 글자 카드였는데 그 글 안은 못 봄). 서명 주소가 끝나면 글 안 사진도 깨질 수 있음. 직접 만든 썸네일을 사진 버튼으로 올린 글(가습기·하이닉스·코스피)은 목록에 잘 나옴.
- **고친 것** (앱 파일만 — 서버·DB·예약 작업·Claude 안 글공장은 그대로, 버전 표기도 1.7.0 그대로):
  - `app.js`: 미리보기가 걸친 복사(긁어서 Ctrl+C·오른쪽 클릭 복사)는 사진을 '📷 사진 n · … — 여기에 사진 넣기' 자리로 바꾸고 제미나이 프롬프트·버튼은 빼고 복사 + 알림. 글자만 고른 복사는 그대로. 복사 칸에 '⭐ 첫 사진이 대표 사진' 안내 한 줄.
  - `studio.js`: 컴퓨터에서 **이미지 복사** — 사진 자리 줄·미리보기 창·썸네일/정보 카드 창. 클립보드에 PNG 그림으로 넣어서 네이버 편집기에 Ctrl+V 하면 네이버에 올라감 (내려받는 파일과 같은 자르기). 검수 전 사진은 내려받기처럼 '사용 가능'으로 바뀜 (상품 장면 이미지는 상품 검수 승인 전엔 사진 줄에 버튼 없음, 미리보기 창에선 '(상품 검수 전)' 표시). 휴대폰은 그대로 '사진에 저장'.
  - `lib.js`: 미리보기 사진 자리에 번호·이름(`data-n`·`data-ph`), '서식 그대로 복사'의 첫 사진 자리에 '⭐ 첫 사진이 대표 사진이 돼' 안내.

- **확인 못 한 것**: '이미지 복사'로 넣은 그림이 네이버 편집기에서 실제로 네이버 사진으로 올라가 대표 사진이 되는지 — 나는 네이버에 로그인할 수 없어서 사용자가 한 번 확인해야 해. 시험 브라우저(Chromium)에서는 클립보드에 PNG 그림이 들어가는 것까지만 확인했어. 다른 브라우저가 그림 복사를 막으면 '내려받아서 올려줘' 알림이 떠.
