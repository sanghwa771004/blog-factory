# 글공장 점검 보고서 (2026-10-21)

대상: 1.0.0(저장소 `296c83e`, 태그 `v1.0.0`, 원격 가지 `backup/v1.0.0`) → 이번 작업 결과 1.1.1.
방법: 코드 전체 읽기, 실서버 DB·함수·예약 작업 상태 확인, 자동 테스트(단위·DB·화면·실서버 API), 정책 공식 자료 확인.

## 1. 한 줄 요약
1.0은 "원고 발행표"로는 동작했지만, **게시 채널과 수익 모델이 글자 한 칸에 섞여 있어서 맞지 않는 조합을 막을 수 없었고, 발행 전 검사·실적·상품 정보가 없었고, 접속 코드가 주소창에 그대로 있었어.** 1.1에서 이 구조를 바꿨고, 1.1.1에서 남은 버그와 정책 정보를 고쳤어.

## 5. 그대로 둔 것 / 한계
- **자동 게시 없음**: 네이버 블로그·티스토리는 글쓰기 API가 없어서 복사·붙여넣기. 앱이 대신 올리지 않아.
- **실적 자동 수집 없음**: 쿠팡 리포트 API는 최종 승인 뒤에만, 토스 API는 신규 신청을 안 받음 → 직접 입력·파일 올리기.
- **자체 클릭 추적 없음**: 링크를 중간 주소로 바꾸면 제휴사 규정 위반이 될 수 있어서 일부러 안 만듦. 클릭 수는 제휴사·블로그 통계 숫자.
- **검색량·경쟁도 실제 숫자 없음**: 조회할 수 있는 공식 API를 연결하지 않아서 주제 점수는 AI 추정·내 실적 기반 상대 평가 (화면에 그렇게 표시).
- **예전 방식 호환**: 1.0 화면이 쓰던 `x-app-token` 머리글 로그인은 아직 받아줌(옛 화면이 자동 업데이트될 때까지). 모든 기기가 1.1로 바뀐 걸 확인하면 끄는 게 좋아 (P2).
- 1.0 작가가 쓴 기존 원고는 발행 전 검사에서 오류가 나올 수 있어 (빈 경험 칸, 링크 없음 등). 1.0의 '단일 상품 솔직 리뷰형'은 '실제 경험 후기'로 옮겨져서, 경험을 적거나 글 유형을 '장단점 분석'으로 바꿔야 발행 준비 완료가 돼.
