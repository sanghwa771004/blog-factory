# 제휴·광고 정책 확인 (2026-10-21)

앱의 수익 모델·채널 정보(설정 > 수익 모델 / 게시 채널 / 조합표)는 이 문서의 공식 자료로 채웠어.
DB에는 `supabase/migrations/008_policy_seed.sql`(처음 값)과 `010_policy_update.sql`(이번에 고친 값)로 들어가 있어.

- **확인 날짜는 모두 2026-10-21.** 정책은 바뀌니까 3~6개월마다 다시 확인해줘.
- `공식` = 회사·기관이 직접 낸 문서, `2차` = 기사·블로그. 2차 자료만 있는 건 앱에서 '확인 필요'로 남겼어.
- 수수료율은 바뀌니까 **앱 계산에 넣지 않았어.** 아래에 적힌 숫자는 그날 공식 문서에 적혀 있던 참고값이야.

## 1. 쿠팡 파트너스
근거: 쿠팡 파트너스 이용가이드 PDF — https://partners.coupangcdn.com/partners-guide/partners-guide-20260611145240.pdf (공식)

- **고지 문구(권장 문구)**: "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." → 앱 고지문을 이 문구로 바꿈 (1.0은 "이 포스팅은…").
- **위치**: "문구는 게시물의 제목 또는 첫 부분에 기재". 제목에 넣으면 잘리지 않게. 추천과 같은 언어로.
- **모든 게시물**: "파트너스 링크가 있는 모든 게시물에는 … 경제적 이해관계를 표시해야 해요!"
- **채널**: 커뮤니티·유튜브·SNS·블로그·지식in·모바일 앱. 링크·배너가 있는 모든 페이지를 등록해야 함.
- **링크**: "쿠팡 페이지의 URL을 그대로 복사하거나, 쿠팡 내 공유 기능을 사용하면 수익으로 집계되지 않습니다." → 앱 검사에 '쿠팡 주소 그대로 넣은 링크' 경고 추가.
- **본인 구매**: "본인 링크를 통한 자가 구매는 실적이 집계되지 않아요."
- **금지**: 자동 실행·무효 클릭, 플로팅·커버형 배너, 제3자 지식재산권 침해, 성인·불법 매체, 동의 없는 메일·메신저·SMS 광고, 무분별한 댓글, 미공개 프로모션 사전 광고, 활동 금지 사이트, 부당·허위·과장 광고, AI 가상인물 추천 시 표시 의무, 쿠팡 키워드 검색광고·도메인.
- **대량 생산 글**: "단순 구매링크만 남기는 목적의 콘텐츠 혹은 프로그램에 의해 양산된 콘텐츠는 대부분의 플랫폼 운영 정책을 위반하여 패널티 대상".
- **리포트**: 기간별(일·월), 실적 상세(최대 90일, 상품·링크 형태·채널 ID·하위 ID·주문 건수 등), 수익 요약·정산·지급. 다음 날 오후 반영, 내려받기 가능. 취소·반품은 빠지고 음수로 보일 수 있음.
- **집계 기간**: 접속 후 24시간 안 구매.
- **정산**: 발생 월 다음 달 25일 확정, 다다음 달 15일 지급, 월 1만 원 이상(모자라면 최대 6개월 이월), 월 상한 3천만 원, 원천세 공제(세율은 가이드에 없음). 지급 전 최종 승인 필요(누적 판매 15만 원 이상이면 채널 심사).
- **수수료(참고값)**: "회사가 정한바에 따릅니다 (단, 별도로 정하지 않은 상품의 경우 결제금액의 3% 적용)".
- **API**: 상품·딥링크·리포팅 API는 최종 승인 뒤에만. 앱에는 연결하지 않음.
- 2차: 2025-10 쿠팡이 강제 이동(납치) 광고 파트너 10여 명을 형사 고소 — https://biz.sbs.co.kr/amp/article/20000263503
- **확인 필요**: 단축 URL·리디렉션 허용 여부(가이드에 언급 없음), 리포트 파일 형식·열 이름, 인스타·쓰레드별 표시 위치, 활동 금지 사이트 목록.

## 2. 토스쇼핑 쉐어링크
근거: https://sharelink-docs.toss.im (공식, 목차 https://sharelink-docs.toss.im/llms.txt)

- **고지(의무)**: "대가성 문구 표시는 선택이 아니라 반드시 지켜야 하는 의무예요." — https://sharelink-docs.toss.im/disclosure/disclosure.md
  - 권장: "이 콘텐츠는 토스쇼핑 쉐어링크 활동의 일환으로, 링크를 통한 구매가 발생하면 일정 수수료를 지급받습니다."
  - 짧은 문구: "[광고] 토스쇼핑 쉐어링크 활동으로, 링크 구매 시 수수료를 지급받습니다."
  - 블로그: 제목, 도입부 또는 상품 소개 바로 앞. 인스타·숏폼: 첫 화면에 보이는 앞부분. '더보기' 뒤에 숨기면 안 됨. `#ad`·`#sp`·'제휴 링크'만, '광고'·'제휴'만 쓰는 건 안 됨.
  - → 1.0의 토스 문구("…제공받을 수 있습니다")는 공식 문구가 아니고 애매한 표현이라 1.1에서 공식 문구로 바꿈.
- **가입**: 사업자 아니어도 가능, 만 19세 이상, 외국인 불가 — https://sharelink-docs.toss.im/start.md
- **채널 등록 필수**, 남의 주소 금지 — https://sharelink-docs.toss.im/start/channels.md
- **금지**: 무효 클릭·자동 실행, 플로팅 배너, 동의 없는 광고 메시지, 관계없는 댓글, 토스 키워드 검색광고·도메인, 토스 사칭, 허위·과장, 상품 이미지 변형, 성인·불법 매체 — https://sharelink-docs.toss.im/help/operations/policy.md
- **수익 인정**: 클릭 후 24시간 안 결제, 마지막 클릭 기준. 본인·가족·지인 교차 구매 제외, 구매확정 전 취소·환불 제외, 배송완료 7일 뒤 자동 구매확정 — https://sharelink-docs.toss.im/income/earnings/earnings-rules.md
- **지급**: 구매확정 달의 다음 달 25일, 잔액 10원 이상, 비사업자 3.3% 원천징수 — https://sharelink-docs.toss.im/income/settlement-guide/payment.md
- **실적 화면**: 클릭·판매·환불·판매금액·예상 수익금(약 30분마다, 한 번에 31일), 정산 내역(확정 수익금·세금·실 지급액) — https://sharelink-docs.toss.im/income/performance.md
- **Open API**: 승인받은 사업자만, 지금은 신규 신청 안 받음 → 앱에 연결 안 함.
- **공지(참고값)**: 2026-10-01 이후 구매확정 주문부터 수수료 8%, 오아시스 상품 2026-10-26부터 5%, 2026-11-02(월) 자정 이후 구매확정되는 앱인토스 미니앱 안 주문은 정산 제외 — https://sharelink-docs.toss.im/notice.md
- **확인 필요**: 쓰레드만 따로 다룬 규정, 네이버 블로그만 따로 다룬 규정, 단축 URL 허용 여부, 실적 파일 내려받기, 링크별 통계.
