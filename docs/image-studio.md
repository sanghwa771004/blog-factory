# 이미지 스튜디오 (1.2.0) — 설정·사용 안내

원고에 사진을 만들고·찾고·올려서 사진 자리에 연결하고, 검수한 뒤 내려받아 블로그에 직접 넣는 기능이야.
확인 날짜가 붙은 내용은 그날 공식 문서에서 직접 본 거야. 바뀔 수 있으니 숫자(가격·한도)는 설정에서 고칠 수 있게 해뒀어.

## 1. 어디에 있나
| 화면 | 하는 일 |
|---|---|
| 콘텐츠 > 원고 > **이미지** 칸 | 본문의 `[이미지: 설명]` 자리를 자동으로 찾아 순서대로 보여줌. 자리마다 **AI로 만들기 · 실제 사진 찾기 · 파일 올리기 · 보관함에서 고르기 · 바꾸기 · 다시 만들기 · 미리보기(자르기) · 내려받기 · 빼기 · 사용 완료** |
| 같은 칸 아래 '본문 밖 자리' | 블로그 대표 이미지(16:9), 쓰레드, 인스타 피드(4:5), 스토리·릴스(9:16) |
| 콘텐츠 > 원고 > **카드뉴스** | 원고에서 초안 → 고치기 → PNG 여러 장 (글자는 앱이 그림, AI가 한국어를 그리지 않음) |
| 콘텐츠 > **이미지 보관함** | 만든·찾은·올린 이미지 전부. 어디에 쓰였는지, 출처, 지우기 |
| 수익 > **이미지 비용** | 생성 비용 (수익 통계와 따로 셈) |
| 설정 > **이미지 (AI·사진·비용 한도)** | 키 상태, 모델 이름, 품질, 하루 한도, 한 달 예산, 환율, 가격표 |

흐름: 원고 고르기 → 이미지 자리 확인 → 만들기·찾기·올리기 중 고르기 → 미리보기 → 결과 고르기(자리에 연결) → **검수 완료하고 내려받기** → 블로그에 직접 올리기 → **사용 완료** 표시

## 2. 필요한 Supabase Secrets (이름만 — 값은 절대 저장소·채팅·앱에 넣지 마)
| 이름 | 쓰는 곳 | 없으면 |
|---|---|---|
| `CF_ACCOUNT_ID` · `CF_API_TOKEN` | **무료** AI 이미지 만들기 (기본 모델 `cf-flux-1-schnell`) | 무료 모델 AI 버튼이 잠기고 '없음'으로 이유를 보여줌 |
| `OPENAI_API_KEY` | (선택·유료) AI 이미지 만들기·고치기 | AI 버튼이 잠기고 '키 없음'으로 이유를 보여줌. 사진 검색·올리기·카드뉴스는 그대로 됨 |
| `PEXELS_API_KEY` | 실제 사진 검색 | 사진 검색이 잠기고 '직접 올리기'로 안내. 나머지는 그대로 됨 |
| `EDGE_WALL_SECONDS` (선택) | 서버 일꾼 하나가 일하는 최대 초 | 안 넣으면 150 (무료 요금제). 유료 요금제로 바꾸면 400 |

`SUPABASE_URL`·서버 키는 Supabase가 자동으로 넣어줘서 따로 할 일 없어. 키는 서버(Edge Function)만 읽고, 앱 화면에는 '있음/없음'만 와.
Secrets는 프로젝트에 한 번만 넣으면 서버 함수 두 개(`blog-app`, 생성 전용 `blog-gen`)가 같이 써.

## 3. 키 발급하고 넣는 법
### OpenAI (확인: 2026-10-22)
1. https://platform.openai.com/api-keys 에 로그인 → **Create new secret key** → 이름 `글공장` → 나온 키를 복사해 (한 번만 보여줘).
2. 결제 수단·크레딧이 있어야 써져. 크레딧이 없으면 앱에 'OpenAI 잔액·한도가 부족해'로 떠.
3. GPT Image 모델은 **조직 인증(Organization Verification)** 이 필요할 수 있어 (OpenAI 이미지 가이드: "you may need to complete the API Organization Verification"). 안 돼 있으면 앱에 '조직 인증 필요'로 떠. 인증에는 실물 신분증 촬영이 필요해 (OpenAI 도움말).
4. **OpenAI 쪽에도 한도를 걸어둬** — 앱 한도와 별개로 마지막 안전장치야:
   https://platform.openai.com/settings/organization/limits → **Spend** → **Edit spend limit** → *Monthly spend limit*에 금액 (예: 3달러) → **Enforce a hard limit** 켜기 → **Save**.
   OpenAI 문서: 한도에 닿으면 요청이 429로 막히고, "Enforcement is not instantaneous, so recorded spend can slightly exceed the configured amount."
### Pexels (확인: 2026-10-22)
- **지금은 새 키 발급이 멈춰 있어.** Pexels API 페이지(https://www.pexels.com/api/)에 "New API key issuance is currently paused and cannot be requested."라고 적혀 있어 (설명서 페이지에는 아직 '바로 받을 수 있다'고 남아 있음). 그래서 키가 없으면 사진 검색은 잠긴 채로 두고 직접 올리기를 쓰면 돼.
- 발급이 다시 열리면: Pexels 계정으로 로그인 → https://www.pexels.com/api/ → **Get Started** → 키 복사.
- 기본 한도: 시간당 200번, 한 달 20,000번 (Pexels 설명서). 앱은 여유를 두고 시간당 150번·한 달 18,000번에서 멈춰.
### Supabase에 넣기
1. https://supabase.com/dashboard/project/oxewhsqmdkiasckvnyua/functions/secrets
2. **Add new secret** → Name `OPENAI_API_KEY`, Value에 키 붙여넣기 → **Save** (Pexels는 `PEXELS_API_KEY`)
3. 다시 배포할 필요 없어 (Supabase 문서: "You don't need to re-deploy after setting your secrets. They're available immediately in your functions.")
4. 앱 **설정 > 이미지**에서 'OpenAI 키: 있음'으로 바뀌었는지 확인
- 키가 샜다고 생각되면: OpenAI 키 화면에서 그 키를 지우고(Revoke) 새로 만들어 같은 이름으로 다시 Save.

## 4. 비용 한도 설정 (앱: 설정 > 이미지)
| 항목 | 기본값 | 범위 | 뜻 |
|---|---|---|---|
| 하루 생성 한도 | 5장 | 0~50 | OpenAI까지 간 요청 수로 셈 (키·모델·잔액 오류처럼 만들기 전에 거절된 건 안 셈). 0이면 AI 생성 끔 |
| 한 달 예산 | 2달러 | 0~500 | 이번 달 쓴 돈 + 이번 요청 예상 비용이 예산을 넘으면 만들기 전에 막음 |
| 품질 | 보통(medium) | 낮음~최고 | 높을수록 비쌈 (아래 표) |
| 만들기 모델 | `gpt-image-2.5-flare` | 영문 소문자·숫자·`.-_` | 계정에서 안 되면 '쓸 수 없는 모델'로 떠 → 아래 표의 다른 모델 이름으로 바꿔 |
| 고치기 모델 | `gpt-image-2.5-sunburst` | 〃 | AI 이미지를 바탕으로 다시 만들 때 |

모델을 바꾸면 앱이 그 모델에 맞춰 보내 (OpenAI API 레퍼런스·모델 페이지, 2026-10-22 확인):
| 모델 | 크기 | 품질 | 예상 비용 |
|---|---|---|---|
| `gpt-image-2.5-flare` · `gpt-image-2.5-sunburst` | 원하는 비율 그대로 (예: 16:9 → 1536×864) | 5단계 | 설정의 가격표 × 공식 계산기 토큰 |
| `gpt-image-2` | 원하는 비율 그대로 | 낮음·보통·높음 | 공식 Standard 가격을 확인 못 해서 **넉넉하게** 잡음 (gpt-image-1 장당 가격) |
| `gpt-image-1.5` · `gpt-image-1` · `gpt-image-1-mini` (OpenAI가 '이전 모델(Deprecated)'로 표시) | 1024×1024·1536×1024·1024×1536 중 방향이 같은 것 → 만든 이미지를 그 자리에 연결하면 내려받을 때 만들 때 고른 비율로 자름 (미리보기에서 바꿀 수 있음) | 낮음·보통·높음 | 각 모델 페이지의 장당 가격 (예: 1.5 보통 1024×1024 = $0.034) |
| 그 밖의 이름 | 표준 크기 3가지 | 낮음·보통·높음 | 넉넉하게 잡고, 사용량으로 계산하지 않음 (청구액은 직접 확인) |
모델이 못 받는 품질(예: 1.5에 '아주 높음')을 고르면 가까운 것(높음)으로 바꿔서 보내. OpenAI가 크기·품질을 거절하면 '이 모델이 그 크기·품질을 지원하지 않아'로 알려줘 (모델을 또 바꾸라고 하지 않음).
| 환율 | 비어 있음 | 100~10,000원 | 원/달러. **기준일·출처도 같이** 넣어 (예: 2026-10-22, 은행 매매기준율). 비어 있으면 원화 합계를 안 보여줘 |
| 가격표 | 이미지 출력 30·이미지 입력 8·텍스트 입력 5 달러/100만 토큰 (2026-10-22 OpenAI 가격 페이지) | | 가격이 바뀌면 고치고 확인 날짜도 고쳐 |

예상 비용 (프롬프트 약 270토큰, 2026-10-22 가격·OpenAI 가이드 계산기 토큰 기준, **예상치**):
| 비율 (요청 크기) | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 16:9 · 9:16 (1536×864) | 약 0.005달러 | 약 0.010달러 | 약 0.034달러 |
| 4:3 (1280×960) | 약 0.006달러 | 약 0.012달러 | 약 0.043달러 |
| 4:5 (1024×1280) | 약 0.007달러 | 약 0.013달러 | 약 0.047달러 |
| 1:1 (1024×1024) | 약 0.007달러 | 약 0.015달러 | 약 0.054달러 |
고치기(바탕 이미지 넣기)는 이미지 입력이 더해져 보통 품질 4:3에서 약 0.024달러. 기본값(보통·하루 5장·한 달 2달러)이면 한 달 최대 150장 정도라 예산 안에서 멈춰.

**비용 상태 뜻** — 실제 청구액을 OpenAI에서 자동으로 가져올 방법이 없어서 이렇게 나눠:
| 상태 | 뜻 |
|---|---|
| 예상 | 요청 전에 계산한 값 |
| 사용량 기준 | OpenAI가 응답에 준 사용 토큰 × 가격표 (이것도 계산값이지 청구서가 아님) |
| 청구액 확인 | 네가 OpenAI 사용량 화면(https://platform.openai.com/usage)에서 보고 직접 넣은 값 |
| 청구 없음 | 청구 안 된 걸 확인함 (0으로 셈) |
| 확인 필요 | 시간 초과·중간에 멈춤처럼 청구됐는지 모르는 경우 → 사용량 화면에서 확인하고 고쳐줘 |
예상 비용과 실제 청구액은 다를 수 있어. 합계는 기록마다 '청구액 확인 > 사용량 기준 > 예상' 순으로 가장 정확한 값을 써.

**수익 통계와의 관계** — 이미지 비용은 실적의 '비용' 칸과 **따로** 셈. 수익 탭에 '이미지 비용'과 '이미지 비용을 뺀 순수익'을 따로 보여주고, 원고별로 몇 번(몇 건) 들어갔는지도 보여줘. 실적 입력의 '비용' 칸에 이미지 비용을 또 적으면 두 번 빠지니까 적지 마.

**남용 막기** — 한 번에 한 장, 생성 버튼을 직접 눌러야 하고, 누르기 전에 모델·크기·품질·예상 비용·오늘 남은 횟수가 보여. 같은 버튼을 여러 번 눌러도 요청 번호가 같아서 한 번만 만들어. 동시에 두 장은 DB가 막아. 대량 생성 기능은 없어. 실패는 저절로 다시 시도하지 않아 (두 번 청구 방지) — 화면에 이유와 다시 해도 되는지 알려줘.

## 5. 저장·보안
- 파일은 Supabase Storage **비공개 버킷 `post-images`** (공개 아님, 접근 정책 없음 → 서버만 올리고 읽음). DB에는 정보(출처·프롬프트·크기·검수 상태·비용)만 있어. 앱은 로그인한 기기에만 서버가 만든 **1시간짜리 서명 주소**로 보여줘.
- 무료 요금제 파일 저장 공간은 1GB (Supabase 문서). 앱은 900MB가 차면 새로 저장을 멈추고 알려줘. 보관함에서 안 쓰는 이미지를 지우면 돼.
- 지우기: 어느 원고(휴지통 원고 포함)·카드뉴스에서든 쓰고 있으면 못 지우고 어디서 쓰는지 알려줘. 원고를 지워도 이미지는 보관함에 남아 (다른 원고에서 다시 쓸 수 있게).
- 직접 올리기: JPEG·PNG·WebP만, 8MB까지. 앱이 긴 변 2,560px로 줄여 다시 저장하고, 서버가 파일 안쪽을 다시 확인해 가짜 확장자를 거절하고 위치(GPS)·카메라 정보 같은 숨은 정보를 지워. 다른 사람 사진이면 쓸 권한이 있는지 확인하는 칸을 꼭 눌러야 올라가.

## 6. 안전장치
- AI 이미지는 일반적인 상황 삽화·배경용. 실제 상품 사진·브랜드 로고·가격·인증 마크·구성품·후기 장면을 AI로 만들지 않게 프롬프트에 규칙이 늘 붙고, 그런 요청을 쓰면 만들기 전에 막아.
- 상품 글의 '실제 사진 필요' 자리(구성품·박스·라벨·성분표·화면·버튼 등)는 **파일 올리기**를 먼저 보여주고, AI로 만들려면 '실제 상품이 아니라 일반 장면으로 만들게'를 체크해야 해 (서버도 확인하고, 체크한 사실을 생성 기록에 남김).
- AI에 같이 보내는 맥락(제목·소제목·앞뒤 문장)에서는 이 글에 연결한 상품의 이름·브랜드·모델명과 가격(29,900원·3천원·2만 9천원 같은 것)·인증·순위 표현, 모델 번호처럼 생긴 것(V12·SM-G998N)을 지우고 보내. A4·PM2.5·LED 3개 같은 보통 말은 그대로 둬. 영문 브랜드는 낱말로만 찾아 (LG가 algorithm 안에서 걸리지 않게).
- '글자 없이', '글자나 로고 없이', '로고를 지운', 'no text or logos', 'text-free'처럼 **넣지 말라는 말은 막지 않아**. 뒤에서 다시 '로고를 크게 넣어줘'처럼 넣어달라고 하면 막아.
- AI 이미지 안에는 글자를 넣지 않아. 제목·설명·숫자는 카드뉴스에서 앱이 그려.
- 새 이미지는 모두 '검수 전'. 발행 전 검사에서 검수 안 된 이미지·실제 사진이 필요한 자리의 AI 이미지·설명이 원고와 안 맞는 이미지를 알려줘. 대체 텍스트(alt)는 자동으로 만들고 고칠 수 있어.
- AI 이미지·실제 사진·직접 올린 사진은 칸마다 색 표시로 구분돼.
- Pexels 사진: 사진가 이름과 사진 페이지 링크, 'Photos provided by Pexels' 링크를 보여주고, 출처 문구를 자동으로 만들어 보관. Pexels가 준 이미지 주소를 고치지 않고 그대로 써.

## 7. 블로그에 넣는 법
- 미리보기 > **검수 완료하고 내려받기**: 아이폰은 공유 창에서 '이미지 저장', PC는 파일로 받아져. 여러 장은 '전부 내려받기'(PC는 ZIP).
- 파일 이름이 `키워드(없으면 제목)-사진순서-용도.jpg` (예: `무선청소기-보관-01-blog_body.jpg`) 라서 순서대로 넣기 쉬워. 복사 칸(HTML·글자)에도 사진 자리마다 파일 이름과 설명이 들어가.
- 네이버 블로그·티스토리에 자동으로 올리는 기능은 **없어** (공식 글쓰기 API·권한이 확인되지 않음). 받은 파일을 직접 올려줘.

## 8. 오류가 뜨면

## 무료 AI 이미지 (Cloudflare Workers AI) — 1.2.0 추가

- 기본 생성 모델은 `cf-flux-1-schnell` (Cloudflare Workers AI의 FLUX.1 schnell). OpenAI 없이 무료로 만든다.
- 무료 플랜(Workers Free)은 **하루 10,000 뉴런**까지 무료, 넘으면 오류로 실패만 하고 청구되지 않는다 (매일 00:00 UTC = 오전 9시에 다시 채워짐). 공식: https://developers.cloudflare.com/workers-ai/platform/pricing/ (2026-10-24 확인)
- 한 장 = 글 모델(llama-3.3-70b)로 한국어 요청서를 영어 프롬프트로 바꾸는 데 약 50 뉴런 + 이미지 1024×1024(4타일×4.8 + 단계×9.6) 약 58~96 뉴런 → **하루 약 70~100장** (계산값, 실측 아님).
- 1024×1024 한 크기로만 만들고, 내려받을 때 고른 비율로 자른다. 품질 = 그리는 단계 수(낮음 4 · 보통 6 · 높음 8, 최대 8).
- 고치기(편집)는 못 한다 → 설명을 바꿔 새로 만들기. 글자·손은 약하다 (원래 이미지 안에 글자는 넣지 않음).
- 생성 기록은 공급자 `cloudflare`, 비용 `청구 없음`·$0으로 남는다. 하루 생성 한도(설정)는 그대로 적용된다.
- 넣는 법: Cloudflare 무료 가입 → 왼쪽 AI → Workers AI → Use REST API → Create a Workers AI API Token → Create API Token → Copy API Token, 같은 화면 Get Account ID 복사 → Supabase Secrets 에 `CF_ACCOUNT_ID`, `CF_API_TOKEN`.
- 2026-10-25 실서버에서 5장 만들어 봄: 장당 6초 안팎, 모두 성공·청구 없음. 결과는 `docs/testing-1.2.0.md` '실서버 점검'.
- 잘 나오게 쓰는 법: 사진 자리 설명은 **눈에 보이는 것**으로 (무엇이·어디에·어떤 빛). 글 모델이 모르는 한국 음식·물건(예: 소금빵)은 '추가 요청'에 생김새를 적어줘 (예: 작은 롤빵 모양, 윗면에 굵은 소금). 글자·숫자가 있어야 하는 물건(포장·화면·계기판)은 피하거나 카드뉴스로.
- 하루 생성 한도(설정 > 이미지, 기본 5장)는 무료 모델에도 적용돼. 무료 모델만 쓸 거면 20~30장으로 올려도 Cloudflare 무료 한도(하루 약 70~100장) 안이야.
