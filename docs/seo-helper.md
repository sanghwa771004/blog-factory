# 검색 노출 점검 (1.3.0 도입 → 1.3.1 정확성 수정)

홈의 **검색 노출 점검**과 원고 검사의 검색 관련 항목을 설명해. 모든 항목은 **알려만 주고 발행을 막지 않아** (경고·참고). 검색 순위를 보장하는 규칙은 없고, 네이버가 순위 공식을 공개하지 않아서 네이버가 밝힌 방향에 맞춰 **앱이 정한 권장 기준**으로 점검해.

화면에서는 줄마다 근거의 종류를 붙여서 보여줘:

| 표시 | 뜻 |
|---|---|
| 앱 권장 기준 | 앱이 정한 숫자 (예: 키워드 3단어 이상, 링크 2개까지, 하루 1편, 주력 주제 70%). 네이버가 숫자로 밝힌 기준이 아님 |
| 내 기록 | 네가 앱에 남긴 원고·게시 기록으로 계산한 값 |
| 실측 데이터 없음 | 검색량·경쟁도를 조회하지 않은 참고 정보 (예: 시즌 달력) |

## 무엇을 점검하나

| 방법 | 앱에서 하는 일 | 어디서 |
|---|---|---|
| 주제 하나를 깊게 | 설정의 **주력 주제**(60자)와 **주력 주제 낱말**(쉼표로, 300자). 글마다 주제와 맞는지 **근거**와 함께 보여줌 (아래 '주력 주제 판정'). 홈에는 **최근 게시한 글** 중 주력 주제 글 비율 (네이버 블로그와 다른 블로그·사이트는 따로, 목표 70%는 앱 권장 기준) | 설정 > 자동 글쓰기, 원고 검사, 홈 |
| 3~5단어 키워드 | 키워드가 1~2단어면 **참고**로 알려줌. 검색량·경쟁도는 조회하지 않아서 '경쟁이 높다'고 단정하지 않음 | 원고 검사 |
| 시즌 2~4주 앞 | 오늘부터 2주·4주 뒤 달의 주제(앱에 적어 둔 달력 — 실측 아님) + 버튼으로 주제 추천 요청 | 홈 |
| 하루 발행량 | 기본·권장은 하루 1편. 2~3편을 고르면 **그대로 두고** 권장과 다르다는 것만 보여줌. 고른 값보다 많이 잡힌 날을 표시. 자동 작가가 다음 실행에 새로 쓸 예정 편수와 이미 잡힌 원고 수를 따로 보여줌 | 설정, 홈 |
| 내 경험 한 줄 | 자동 작가가 블로그 글 첫 부분에 `[내 경험: …]` 1곳. 빈 칸은 글에 그대로 보여서 '발행 준비 완료'를 막지만, **정보 글은 칸을 지우고 경험 없이 올려도 돼**. 경험이 없으면 경고만 (`no_own_experience`). 실제 경험 후기 글은 경험이 없으면 기존대로 막음 | 원고 |
| 직접 촬영 사진 | 자동 작가가 사진 자리 1곳을 `[이미지: (직접 찍기) …]`로 표시. 직접 올린 사진은 **출처를 골라야** 직접 촬영으로 셈 (아래 '이미지 출처') | 이미지 스튜디오, 원고 검사 |
| AI 이미지 표시 | 네이버 블로그 글에 AI 이미지가 있으면 'AI 활용' 표시 안내 (2026년 7월 기준 블로그는 자율) | 원고 검사 |
| 링크 중간·끝 | 링크 3개 이상 `too_many_links`, 첫 소제목 앞(또는 글 앞 15%) `link_too_early` | 원고 검사 |
| 광고 표시 | 기존 그대로: 복사할 때 수익 모델별 공식 고지문을 맨 위에 | 복사 |
| 쇼핑 커넥트 | 미가입이면 홈에 공식 소개 링크 | 홈 |

## 주력 주제 판정 (1.3.1)
외부 AI 없이 낱말로만 봐. 근거는 키워드·제목(주된 근거), 카테고리(약한 근거), 소제목·본문(보조 근거).

| 판정 | 조건 | 검사 결과 |
|---|---|---|
| 주력 주제와 맞음 | 키워드나 제목에 ① 설정의 '주력 주제 낱말' 하나, ② 주력 주제 이름 전체, ③ 주력 주제 이름의 낱말 두 개 이상 중 하나 (주력 주제가 한 낱말이면 그 낱말) | 참고 (근거 표시) |
| 판단 어려움 | 키워드·제목에 주력 주제 이름의 낱말이 **하나뿐**(예: '겨울' — 넓은 낱말이라 '겨울 패딩'도 걸릴 수 있음), 또는 소제목·본문에만 있음, 또는 본문 없는 게시 기록인데 카테고리만 맞음 | 경고 `focus_unclear` (근거 표시) |
| 주력 주제 밖 | 그 밖 — 본문이 있는 글에서 **카테고리만 주력 주제로 적은 글도 여기** | 경고 `off_focus` (근거 표시) |

낱말 찾는 규칙: 영어·숫자 낱말은 낱말 경계로만('it' ≠ 'limited'), 한국어 낱말은 한 낱말 안에서만 찾고 띄어쓰기를 넘지 않음('전기요' ≠ '전기 요금', '히터'는 '전기히터'에서 찾음), 띄어 쓴 낱말('전기 장판')은 띄어쓰기가 달라도 찾음, 한 글자 낱말(책·술·옷)은 낱말 그대로(+조사)일 때만.

주력 주제 이름이 넓으면('계절템·겨울 가전') 대부분 글이 '판단 어려움'으로 나올 수 있어 → 설정의 '주력 주제 낱말'에 그 블로그의 핵심 낱말(예: 히터, 전기요, 온수매트, 가습기, 제습기)을 적으면 정확해져. 카테고리만으로는 주제 글로 보지 않아. 자동 작가도 1.3.1부터는 카테고리를 주력 주제 이름으로 덮어쓰지 않고 글의 세부 분류로 적어 (실제 예약 작업에는 2026-10-26에 넣었어 — `docs/auto-writer-prompt.md` '반영 상태').

## 주력 주제 비율 (1.3.1)
- **게시를 마친 글만** 셈: 게시 완료·실적 수집 중·성과 분석 완료. 초안(검수 필요·발행 준비·예약)·지운 글·실패한 글은 빼.
- '최근' 순서: 게시일(`published_on`) → 없으면 예정 발행일(`publish_date`) → 그것도 없으면 만든 날.
- 게시한 글이 없으면 **데이터 없음** (0%라고 하지 않음).
- 최근 30개 기준. '판단 어려움'은 맞는 글로 세지 않고 따로 개수로 보여줘. 판정할 수 없는 글(주력 주제 낱말이 없음)은 비율에서 빼.

## 이미지 출처 (1.3.1)
| 출처 | 정해지는 방법 |
|---|---|
| 직접 촬영 | 직접 올린 사진에서 사용자가 '내가 직접 찍은 사진'을 고른 경우만 |
| 공식 제공 | 직접 올린 사진에서 '제조사·판매처가 준 공식 이미지'를 고름 |
| 외부 제공 | Pexels에서 가져온 사진, 또는 직접 올린 사진에서 '다른 곳에서 받은 사진'을 고름 |
| AI 생성 | AI로 만든 이미지 |
| 출처 확인 필요 | 직접 올렸는데 출처를 안 고름 — 1.3.0까지 올린 사진도 모두 여기 (직접 촬영으로 소급하지 않음) |
| 카드뉴스 | 앱이 그린 카드뉴스 PNG |

파일 올리기 창, 미리보기(검수) 창, 보관함 상세에서 출처를 고르거나 바꿀 수 있고, 슬롯 표시·보관함·게시 원고 미리보기에 같은 이름으로 보여줘. 출처를 안 고른 사진이 연결돼 있으면 `image_source_unknown` 경고.

## 솔직한 한계
- 숫자 기준(70%·3단어·링크 2개·앞 15%·하루 1편)은 앱이 정한 권장 기준이야.
- 주력 주제 판정은 낱말 기준이라, 주제 안의 글이어도 키워드·제목에 주제 낱말이 없으면 '판단 어려움'·'주력 주제 밖'으로 나올 수 있어 → 설정의 '주력 주제 낱말'에 그 글의 핵심 낱말(예: 전기요, 온수매트)을 더하면 돼.
- 앱은 사진을 누가 찍었는지 알 수 없어서, 사용자가 고른 출처를 그대로 믿어.
- 시즌 달력은 달별로 적어 둔 주제야. 실제 검색량을 조회하지 않아.
