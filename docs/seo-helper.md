# 검색 노출 도우미 (1.3.0)

네이버 검색에 묻히지 않게 도와주는 기능을 한곳에 모았어. 모든 검사는 **알려만 주고 발행을 막지 않아** (경고·확인할 것). 검색 순위를 보장하는 규칙은 없어서, 네이버가 밝힌 방향에 맞춰 앱이 정한 기준이야.

## 무엇이 들어갔나

| 방법 | 앱에서 하는 일 | 어디서 |
|---|---|---|
| 주제 하나를 깊게 | 설정의 **주력 주제**(60자까지). 자동 작가가 자동 글·주제 추천을 그 안에서만 고름. 주제 밖 글은 `off_focus` 경고. 홈에 최근 글 30개 중 주력 주제 비율(목표 70% — 앱이 정한 값) | 설정 > 자동 글쓰기, 홈 |
| 경쟁 적은 3~5단어 키워드 | 키워드가 1~2단어면 `short_keyword` 경고. 자동 작가·주제 추천은 3~5어절 롱테일만 | 원고 검사, 자동 작가 |
| 시즌 2~4주 앞 | 오늘부터 2주·4주 뒤 달의 시즌 주제를 홈에 보여주고, 버튼 하나로 주력 주제 안에서 주제 추천 요청 | 홈 |
| 하루 1편 | 하루 발행 개수 1 권장 안내. 지난 7일~다음 7일에 하루 2편 이상 잡힌 날을 홈에 표시 | 설정, 홈 |
| 사람 손 거친 글 — 내 경험 한 줄 | 자동 작가가 블로그 글 첫 부분에 `[내 경험: …]` 자리를 1곳 남김(빈 칸은 '발행 준비 완료'를 막는 기존 규칙 그대로). 경험이 한 줄도 없으면 `no_own_experience` 경고. '내 경험 채우기'로 넣으면 원고의 경험 칸에도 기록 | 원고, 홈 |
| 사람 손 거친 글 — 직접 찍은 사진 한 장 | 자동 작가가 사진 자리 중 1곳을 `[이미지: (직접 찍기) …]`로 표시. 이미지 스튜디오는 그 자리에서 '파일 올리기'를 앞에 두고, AI로 만들려면 체크를 받음. 연결한 이미지 중 직접 올린 사진이 없으면 `no_own_photo`, 그 자리에 AI 이미지면 `ai_in_own_slot` 경고 | 이미지 스튜디오, 원고 검사 |
| AI 이미지 표시 | AI 이미지가 있으면 네이버 글쓰기의 'AI 활용' 표시를 켜두라고 안내 (블로그는 지금 자율) | 원고 검사 |
| 링크는 중간 1개·끝 1개 | 링크가 3개 이상이면 `too_many_links`, 첫 소제목 앞(또는 글 앞 15%)에 있으면 `link_too_early` 경고. 자동 작가도 2곳까지만, 앞부분에는 안 넣음 | 원고 검사, 자동 작가 |
| 광고 표시는 제목·첫 부분 | 기존 그대로: 복사할 때 수익 모델별 공식 고지문을 맨 위에 붙임 | 복사 |
| 네이버 쇼핑 커넥트 | 미가입이면 홈에 소개 링크. 가입하면 설정 > 수익 모델에서 상태와 공식 고지문을 넣어야 씀 | 홈 |
| AI 말투 줄이기 | 자동 작가·Claude 안 글공장이 틀에 박힌 말("오늘은 ~에 대해 알아볼게요" 등)을 피하고 구체적인 상황으로 씀 | 자동 작가 |

검색 노출 검사는 블로그·웹사이트 채널 글에만 해 (SNS 글은 검색으로 들어오지 않아서 안 봄).

## 바뀐 파일

- DB: `supabase/migrations/014_focus_topic.sql` — 설정에 `focus_topic` 열 하나 (기본 빈칸, 60자 검사). 표·데이터는 그대로.
- 서버: `index.ts` 설정 저장에 `focus_topic`.
- 검사: `checks.js` 12번 (검색 노출), `images.js` (`직접 찍기` 자리·`no_own_photo`·`ai_in_own_slot`·`ai_label`). 서버 폴더 사본도 같음.
- 화면: `app.js` 홈 '검색 노출 도우미', 설정 '주력 주제', `studio.js` '직접 찍기' 자리 안내, `lib.js` 시즌 달력·비율·몰린 날.
- 자동 작가 프롬프트 1.3.0: `docs/auto-writer-prompt.md` (예약 작업 '글공장 자동 글쓰기'에 같은 내용).
- Claude 안 글공장 7: 원고·주제 프롬프트에 같은 규칙.

## 솔직한 한계

- 주력 주제 비율 70%, 키워드 3~5단어, 링크 2개는 **앱이 정한 기준**이야. 네이버가 숫자로 밝힌 기준이 아니야.
- 시즌 달력은 앱에 적어 둔 달별 주제야. 실제 검색량 숫자를 조회하지 않아.
- 앱은 사진을 누가 찍었는지 알 수 없어. '파일 올리기'로 올린 사진을 직접 찍은 사진으로 셈.
- 네이버 쇼핑 커넥트는 가입과 공식 고지문 입력이 따로 필요해. 앱은 링크를 바꾸거나 대신 가입하지 않아.
