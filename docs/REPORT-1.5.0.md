# 글공장 1.5.0 이미지 스튜디오 고품질화 — 보고서 (2026-10-27, 배포 2026-10-28)

목표(사용자 지시서): "이미지 스튜디오 고품질화 프로젝트" — 원고 맥락을 제대로 쓰는 프롬프트(장면 설계서·프리셋), Gemini 추가, 모델 선택·비용 통제, 진짜 제품 사진 참고·고치기·이력, 생성 결과 검수, 모델 비교.

- 대상: 1.4.0(`0c0e84a`, 실서비스) → **1.5.0**. 코드는 가지 `release/1.5.0`.
- **배포 상태: 2026-10-28 배포함** (사용자 승인: 배포만 — Gemini 키·결제 연결과 유료 시험 생성은 안 함). DB·서버·앱 화면·예약 작업·Claude 안 글공장 다 1.5.0이야. 순서와 결과는 9번 배포 기록.
- **유료 API는 한 번도 부르지 않았어.** 모든 테스트는 가짜 공급자·가짜 DB API·로컬 DB(PGlite)로 돌렸고, 서버 테스트는 서버가 127.0.0.1 말고는 연결하지 못하게 띄웠어. 실서비스 DB는 모델별 실제 생성 기록을 보려고 **읽기만** 한 번 했어 (아래 3번). 배포 뒤 점검에서도 이미지는 만들지 않았고, 공급자에는 '연결 확인'(키·모델 조회, 돈 안 듦)만 했어 — 실제로 공급자를 부른 건 키가 있는 Cloudflare 하나야.

## 7. 실제 이미지 API로 테스트하지 못한 것 (검증 안 됨)과 남은 한계

- **어느 공급자로도 실제로 이미지를 만들지 않았어** (배포 뒤 Cloudflare에 '연결 확인'만 — 3번). Gemini 요청 모양(`generateContent`·`imageConfig`·`inline_data`)과 OpenAI 참고 사진(edits 에 `image[]` 여러 장), Cloudflare 참고 사진(`input_image_0~3`)은 공식 문서대로 만들고 가짜 응답으로만 확인했어. 실제로 받아 주는지는 승인받고 한두 장 만들어 봐야 알아 (무료 Cloudflare는 앱에서 만들어 보면 돼).
