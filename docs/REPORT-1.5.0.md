# 글공장 1.5.0 이미지 스튜디오 고품질화 — 보고서 (2026-10-27)

목표(사용자 지시서): "이미지 스튜디오 고품질화 프로젝트" — 원고 맥락을 제대로 쓰는 프롬프트(장면 설계서·프리셋), Gemini 추가, 모델 선택·비용 통제, 진짜 제품 사진 참고·고치기·이력, 생성 결과 검수, 모델 비교.

- 대상: 1.4.0(`0c0e84a`, 실서비스) → **1.5.0**. 코드는 가지 `release/1.5.0`.
- **배포 상태: 배포 안 함.** 지시서대로 로컬 구현·테스트만 했어. 실서비스(DB·서버·앱 화면·예약 작업·Claude 안 글공장)는 1.4.0 그대로야.
- **유료 API는 한 번도 부르지 않았어.** 모든 테스트는 가짜 공급자·가짜 DB API·로컬 DB(PGlite)로 돌렸고, 서버 테스트는 서버가 127.0.0.1 말고는 연결하지 못하게 띄웠어. 실서비스 DB는 모델별 실제 생성 기록을 보려고 **읽기만** 한 번 했어 (아래 3번).

## 7. 실제 이미지 API로 테스트하지 못한 것 (검증 안 됨)과 남은 한계

- **어느 공급자도 실제로 부르지 않았어.** Gemini 요청 모양(`generateContent`·`imageConfig`·`inline_data`)과 OpenAI 참고 사진(edits 에 `image[]` 여러 장), Cloudflare 참고 사진(`input_image_0~3`)은 공식 문서대로 만들고 가짜 응답으로만 확인했어. 실제로 받아 주는지는 배포 뒤 승인받고 한두 장 만들어 봐야 알아.
- GPT Image 2.5의 출력 토큰 수는 공식 계산기가 2.5를 계산해 주지 않아서 GPT Image 2 값으로 추정해. 예상과 사용량 기준이 꽤 다를 수 있어.
- `input_fidelity`(OpenAI 참고 사진 모양 유지 강도)는 2.5에서 되는지 문서로 확인 못 해서 보내지 않아.
- Nano Banana 2.1이 넣는 이미지 한 장을 몇 토큰으로 세는지 문서로 확인 못 해서 넉넉히(1,120토큰) 잡아.
- Cloudflare Gemma 4 검수가 이미지를 data 주소로 받는지는 문서로 확인 못 했어 (안 받으면 '검수 실패'로 나오고 청구 없음).
- AI가 참고한 제품을 다시 그리는 거라 작은 글자·로고·버튼이 바뀔 수 있어. 앱은 비교하라고 안내하고 AI 검수에 '원본과 같은지'를 넣었지만, 같다고 보장하지 못해.
- AI 검수는 의견이야 — 틀릴 수 있고, 같은 이미지라도 모델마다 다르게 말할 수 있어.
- 모델 비교는 내가 매긴 평가만 모아. 비교가 적으면 어느 모델이 낫다고 말할 근거가 안 돼.
- 여러 장(후보·비교)은 동시에가 아니라 한 장씩이라 3장이면 시간이 세 배 걸려.
- 무료 요금제 서버 일꾼 시간(150초) 때문에 Gemini 4K·OpenAI 최고 품질은 '서버가 바빠'로 기다릴 때가 있을 수 있어 (기다리는 시간은 실측 아님).
- 1.5.0 자동 작가 규칙(사진 자리 설명)은 아직 예약 작업에 안 넣었어.
