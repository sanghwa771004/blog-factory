## 실패했던 것 (숨기지 않고 적어둠)
- DB 테스트 1개 실패 → **코드 버그였음**: 이미 잡힌 작업을 다시 잡을 수 있었음. `009_job_lock.sql`로 고친 뒤 통과.
- 규칙 테스트: `[링크2: …]` 버튼 글자 버그 발견 → `checks.js` 고친 뒤 통과.
- 화면 테스트 2개 실패 → 테스트 쪽 문제였음: (1) 같은 글자가 두 군데 있어서 찾기가 애매, (2) 요청 뒤 화면 이동이 끝나기 전에 다음 테스트가 시작. 테스트에 기다리기를 넣어 고침.
- 화면 테스트 1개가 한 번만 실패(원고 요청 화면) → 버튼을 누른 직후 다시 그려지는 타이밍 문제. 상태 확인 기다리기를 넣고 8번 연속 통과.
- 실서버 첫 요청 1개가 pg_net 기본 5초 제한에 걸림(서버가 깨어나는 시간). 20초로 다시 보내서 통과.

## 못 한 것 (안 한 걸 했다고 하지 않음)
- **진짜 아이폰 사파리**에서는 직접 못 눌러봤어 (화면 테스트는 Chromium으로 아이폰 크기·사용자 에이전트 흉내).
- **네이버 블로그·티스토리 에디터에 실제로 붙여넣기**는 못 해봤어 (로그인 필요). 복사되는 HTML 모양은 계산 테스트로 확인.
- **진짜 쿠팡·토스 리포트 파일**은 없어서, 열 이름을 흉내 낸 예시 파일(`tests/fixtures`)로만 올리기를 확인했어.
- 자동 작가가 **실제로 원고를 쓰는 흐름**은 이번에 돌리지 않았어 (발행표가 7일 다 차 있고 대기 작업이 없어서 쓸 게 없었음). 다음에 원고를 요청하면 다음 정기 실행에서 써져.
- 실서버 점검 세션 1개는 로그아웃만 시켜두고 행은 남아 있어 (지우기 요청이 취소돼서). 이 세션으로는 아무것도 못 해.
