## 실서버 점검
배포 전이라 **아직 안 했어** (DB 012 적용에 사용자 확인이 필요해서 멈춤). 배포하면 `tests/live/README.md` 7번 순서대로: 401 확인, 생성 전용 서버(`blog-gen`)가 올라갔고 생성 요청만 받는지, 키 없음 안내, 직접 올리기 → 비공개 서명 주소, 가짜 파일 거절, 점검용 가짜 모델로 생성 흐름(OpenAI 안 부름, blog-gen으로), 같은 요청 번호 다시 보내기, 쓰는 이미지 지우기 거절, 지운 이미지를 카드뉴스 배경으로 못 씀, 통계·백업. 실제 OpenAI·Pexels 호출은 키가 생긴 뒤에.
