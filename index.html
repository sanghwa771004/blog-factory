  5. 쓰레드에 올리기 → 게시, 그리고 발행 완료

글은 어떻게 채워져?

네 Claude 구독으로 매일 아침 9시, 낮 1시, 저녁 7시쯤 자동으로 써서 넣어. 요청한 글을 먼저 쓰고, 앞으로 7일 발행표가 비어 있으면 자동 주제로 채워. 추가 비용은 없어.

급할 땐 Claude 안 글공장에서 바로 쓰면 이 발행표로 들어와.

티스토리 · 네이버

  • 티스토리: 본문에 서식 그대로 복사 붙여넣기 (HTML 모드면 HTML 코드), 태그 칸엔 쉼표 태그, 발행 설정에서 예약 가능
  • 네이버: 서식 그대로 복사 붙여넣기, 발행할 때 예약 가능

두 블로그 모두 글쓰기 API가 닫혀 있어서 붙여넣기 방식이 가장 안전해.

돈 되는 글 공식

  • 롱테일 키워드: "청소기 추천"보다 "원룸 무선청소기 10만원대"
  • 고지문은 맨 위: 공정위 지침상 블로그는 제목이나 본문 첫 부분 (복사할 때 자동으로 붙어)
  • 안 써본 걸 써본 척 금지: 경험 칸은 진짜 경험만
  • 링크는 2개까지, 하루 1~2개 꾸준히
